# Security Policy

## Reporting a vulnerability

Please report security issues through a private advisory:
https://github.com/omarmohelal/turso-platform-sdk/security/advisories/new

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/omarmohelal/turso-platform-sdk/issues

## Scope

This policy covers the TypeScript SDK in `ts/` and the example in `examples/`.

This is an unofficial SDK for the Turso Platform API. It is not affiliated with,
endorsed by, or sponsored by Turso.
