# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/omarmohelal/turso-platform-sdk/security/advisories/new.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/omarmohelal/turso-platform-sdk/issues

## Scope

This policy applies to the generated Omar Mohelal SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Turso Platform public API, generated by
Omar Mohelal. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
